FICHES DE CONTROLE - mode d'emploi
===================================

Une fiche = un fichier .json dans ce dossier + une ligne dans index.json.

NOMS DE FICHIERS
- Le nom du fichier peut contenir des espaces et des accents (ex. "Fiche controle fondations.json").
  Seuls ces caracteres sont interdits : \ / : * ? " < > |
- Le nom du fichier (sans .json) est l'IDENTIFIANT de la fiche : c'est lui qui est enregistre avec
  chaque fiche remplie et chaque demande. Choisir le nom une fois, puis ne plus le changer.

REFERENCE IMPRIMEE
- La reference affichee et imprimee dans le PDF (ex. PR-26_FO36) est le champ "ref" a l'interieur
  du fichier. Elle est independante du nom du fichier.
- Garder le champ "ref" tel quel : il permet aussi de retrouver les fiches enregistrees avant un
  renommage de fichier.

AJOUTER UNE FICHE
1. Copier un fichier existant, le renommer, puis modifier son contenu : "ref", "title", "version",
   mode operatoire, criteres, photos a annexer.
2. Ajouter le nom du fichier dans index.json (liste "fiches"), entre guillemets, separe par une virgule.
3. Deposer le tout dans le depot. Au prochain lancement en ligne, l'application la propose.

CORRIGER UNE FICHE
- Changer librement les textes (titre, "label" des criteres, mode operatoire, noms de photos).
- NE PAS changer l'"id" d'un critere ni la 1re valeur d'une photo ([ "id", "libelle" ]) :
  les reponses deja enregistrees y sont rattachees.
- NE PAS renommer ni supprimer un fichier deja utilise dans des comptes rendus ou des demandes.

SI UNE FICHE N'APPARAIT PAS
L'ecran "Choisir une fiche" signale le fichier en cause (JSON mal forme, fichier introuvable,
nom invalide, criteres manquants...). Les autres fiches continuent de fonctionner.
Verifier aussi que le nom dans index.json est EXACTEMENT celui du fichier (majuscules comprises).
